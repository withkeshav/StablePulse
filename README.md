# StableScope

Professional **USDT & USDC intelligence platform** — peg stress monitoring, cross-chain mint/burn flows, whale-watch anomaly detection, and AI-generated market narratives. Standalone frontend edition.

Created by [Keshav Maheshwari](https://www.linkedin.com/in/withkeshav)

> **Source-available.** Free for personal / non-commercial use. Modification is **not** permitted. See [LICENSE](./LICENSE).

---

## Features

- **Peg Stress Index** — 0–100 risk score driven by peg drift, active alerts, and cross-chain flow pressure.
- **Supply & price history** — 90-day charts per stablecoin, updated on a background sync cadence.
- **Cross-chain mint / burn** — ranked per-chain deltas and a migration detector (which chains are bleeding into which).
- **Whale Watch** — z-score based detection of supply anomalies across chains.
- **AI signal** — narrative headline + per-alert explanations generated by any OpenAI-compatible model (cloud or self-hosted).
- **Alerts hub** — filter by severity / coin, sort by recency / severity / magnitude, group by rule.
- **Multi-coin ready** — the UI is driven entirely by `ACTIVE_STABLECOINS`; adding a coin is a config change.
- **Dark / light / system theme**, compact mode, auto-refresh with a manual **Refresh now** button.
- **Mobile-first** — bottom tab bar, card-based tables, safe-area aware, charts rescale.

## Tech stack

- [Preact](https://preactjs.com) + [Vite](https://vitejs.dev) — main bundle ~52 kB (17 kB gzip).
- [Chart.js](https://www.chartjs.org) — lazy-loaded, only Line/Bar registered (~60 kB gzip, loaded on first chart).
- [Vitest](https://vitest.dev) — unit tests for the pure logic (`formatters`, `derive`).
- **No backend in this repo.** Data comes from a single pre-aggregated `/api/dashboard` JSON.

## How it works

```
Cloudflare Worker (cron background sync)
  ├─ pulls DefiLlama chain balances + CoinGecko prices/tickers
  ├─ generates AI narrative (OpenAI-compatible, keys stay server-side)
  └─ serves ONE cached JSON payload:  /api/dashboard
                    │
Static frontend (Cloudflare Pages / VPS / anywhere)
  └─ fetches /api/dashboard → derive.js computes display stats client-side
```

The frontend makes **one request per refresh** and computes the stress index, chain flows, migration pairs, and whale-watch rows locally in `src/lib/derive.js`.

## Configuration

The API base URL resolves in this order:

1. `window.STABLESCOPE_CONFIG.apiBase` — runtime override (set it in `index.html` or before the bundle loads).
2. `import.meta.env.STABLESCOPE_API_BASE` — build-time env var (`STABLESCOPE_API_BASE=... npm run build`).
3. Default — dev: `http://127.0.0.1:8787`, prod: the Cloudflare Worker URL.

Example runtime override:

```html
<script>
  window.STABLESCOPE_CONFIG = { apiBase: 'https://my-endpoint.example.com' };
</script>
```

**CORS:** the worker must send `Access-Control-Allow-Origin` covering the origin the site is served from (use `*` or list your Pages/VPS domain). Dev (`localhost`) and prod both need to pass.

### Settings (persisted to localStorage)

- Theme (`stablescope:theme`)
- Auto-refresh interval (`stablescope:refresh`) — 1/3/5/10/15 min
- Compact mode (`stablescope:compact`)

## Adding a stablecoin

The frontend is fully registry-driven. Adding a coin is **one config entry** (provided the worker serves its data):

```js
// src/utils/coin-config.js
USDE: {
  symbol: 'USDE',
  coingeckoId: 'ethena-usde',
  llamaStablecoinId: 123,
  color: '#8B5CF6',
  thresholds: { pegCriticalBps: 50, pegWarnBps: 10, chainSpikeUsd: 500e6, megaSupplyUsd: 1e9 },
},
// then add 'USDE' to ACTIVE_STABLECOINS
```

The nav tabs, home stats/charts, chain-flow bars, and whale watch all follow the list automatically. The worker must expose matching payload fields: `usdeDetail` (chain balances), `cgUSDE` / `cgUSDEChart` (Coingecko), and the coin under `allStables.peggedAssets` + `cgSimple`.

### Worker-side scaling playbook (for the data engine, in your other repo)

The free Cloudflare Workers tier caps CPU at **10 ms/invocation** and **50 subrequests/request** — each coin adds DefiLlama/CoinGecko fetches and JSON parsing. To grow the list safely:

- Keep `ACTIVE_STABLECOINS` as a **worker env var** (not baked into the frontend) so adding coins never requires a frontend redeploy.
- **Round-robin coins across cron runs** — process 1–2 coins per run to stay under the CPU budget.
- **Cache raw upstream responses in Workers KV**; parse only the fields the dashboard needs.
- Split aggregation across multiple workers (free plan allows 100) if it grows — each handles a coin subset; the dashboard worker merges.

## AI configuration

AI runs **entirely in the worker** — keys never reach the browser. The frontend is provider-agnostic; it just renders whatever the worker returns (`intelligence.headline` / `narrative` / `implications` and `/api/alert-explain`).

Point the worker at any **OpenAI-compatible** endpoint via env vars:

| Env var | Example |
|---|---|
| `OPENAI_BASE_URL` | `https://openrouter.ai/api/v1` |
| `OPENAI_API_KEY` | your key |
| `OPENAI_MODEL` | `deepseek/deepseek-chat` |

- Generate the narrative during the **cron background sync** so users never wait on the model.
- **Cache `/api/alert-explain` results** (e.g. in KV keyed by alert id) — expanding an alert is the only on-demand AI call and should be instant on repeat.
- The UI degrades gracefully if AI is down or absent (fallback copy), so the app keeps working either way.

## Deploying

### Cloudflare Pages (free, recommended) + existing Worker

```bash
npm install
npm run build
npx wrangler pages deploy dist
```

Point `STABLESCOPE_CONFIG.apiBase` at your worker (or build with `STABLESCOPE_API_BASE`). Confirm the worker's CORS header allows the Pages domain.

### VPS (nginx / Caddy)

The frontend is static files with a configurable API URL — deploy `dist/` anywhere and set `apiBase`. The VPS only serves static assets; **it never calls upstream APIs**, so its IP is never exposed to CoinGecko/DefiLlama rate limits.
