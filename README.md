# StableScope

Professional USDT & USDC Intelligence Platform. Standalone edition — extracted from the keshav-reports monorepo.

Created by [Keshav Maheshwari](https://www.linkedin.com/in/withkeshav)

## Usage

```bash
npm install
npm run dev     # dev server with HMR
npm run build   # production build
npm run preview # preview production build
```

The app fetches data from a Cloudflare Worker at `https://stablescope-cors.keshav-maheshwari.workers.dev`.
