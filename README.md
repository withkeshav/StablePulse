Stablecoin intelligence platform covering **USDT, USDC, DAI, USDe and PYUSD**: peg stress monitoring, cross-chain mint/burn flows, whale-watch anomaly detection, AI-generated market narratives, and a built-in learning tab that explains how stablecoins and pegs actually work.

## Features

- **Peg Stress Index**: a 0-100 risk score driven by peg drift, active alerts, and cross-chain flow pressure.
- **Supply & price history**: 90-day charts per stablecoin, updated on a background sync cadence.
- **Cross-chain mint / burn**: ranked per-chain deltas and a migration detector (which chains are bleeding into which).
- **Whale Watch**: z-score based detection of supply anomalies across chains.
- **AI signal**: narrative headline plus implications generated by any OpenAI-compatible model (cloud or self-hosted) on the backend.
- **Alerts hub**: deterministic client-side alerts (PEG_BREAK, CHAIN_SPIKE, MEGA_SUPPLY, DOM_SHIFT) with severity, magnitude, and explanation; filter by severity / coin.
- **Learn tab**: plain-language lessons on what a stablecoin is, how pegs work, collateral types, depeg causes, and how to read every signal on the dashboard, plus a glossary.
- **Multi-coin ready**: the UI is driven entirely by `ACTIVE_STABLECOINS`; adding a coin is a config change.
- **Themes**: Light default, plus Dark and System. Compact mode, auto-refresh with a manual **Refresh now** button.
- **Mobile-first**: bottom tab bar, card-based tables, safe-area aware, charts rescale.

## Tech stack

- [Preact](https://preactjs.com) + [Vite](https://vitejs.dev): main bundle ~65.79 kB (21.64 kB gzip).
- [Chart.js](https://www.chartjs.org): lazy-loaded, only Line/Bar registered (~59.65 kB gzip, loaded on first chart).
- [Vitest](https://vitest.dev): unit tests for the pure logic (`formatters`, `derive`).
- Optional [Fastify](https://fastify.dev) + SQLite backend (`backend/`) for history accumulation and AI narratives.

## How it works

```
Visitor's browser (no backend required)
  +- DefiLlama /stablecoins, /stablecoin/{id}   live supply + history (browser-direct, CORS-open)
  +- CoinGecko  /simple/price, market_chart, tickers   prices + charts (browser-direct, CORS-open)
  +- derive.js computes stress index, flows, migration pairs, whale-watch rows, alerts

Optional lite VPS backend (same origin via nginx)
  +- /api/healthz, /api/ai (narrative), /api/history (proprietary dataset)
  +- cron jobs: fetch.js (10 min) + ai.js (gated by AI_CADENCE_MIN)
```

The frontend fetches live market data directly in the browser (no API keys needed) and computes all display stats locally in `src/lib/derive.js`. The backend is optional and only powers AI narratives plus a proprietary history dataset. See [docs/architecture.md](./docs/architecture.md) and [docs/api-protocol.md](./docs/api-protocol.md).

## Backend setup (optional)

```bash
cd backend
npm install
cp .env.example .env   # fill in OPENAI_* keys, AI_CADENCE_MIN, etc.
npm run fetch          # backfill the historical dataset from DefiLlama/CoinGecko
npm run ai             # generate one AI narrative immediately
npm start              # serve /api/healthz, /api/ai, /api/history on :8787
```

Deployment artifacts live in `backend/deploy/` (systemd unit, nginx config, crontab). The backend is not required for the core dashboard.

## Configuration

The AI/backend base URL resolves in this order (`src/config.js`):

1. `window.STABLESENSE_CONFIG.aiApiBase` (runtime override, set it in `index.html` or before the bundle loads).
2. `import.meta.env.STABLESENSE_AI_API_BASE` (build-time env var, `STABLESENSE_AI_API_BASE=... npm run build`).
3. Default: `''` (empty) which means same-origin and the AI layer is disabled unless a backend is served alongside.

Example runtime override:

```html
<script>
  window.STABLESENSE_CONFIG = { aiApiBase: 'https://my-backend.example.com' };
</script>
```

The backend is served same-origin behind nginx, so no CORS configuration is needed in production.

### Settings (persisted to localStorage)

- Theme (`stablesense:theme`), default Light.
- Auto-refresh interval (`stablesense:refresh`): 1/3/5/10/15 min.
- Compact mode (`stablesense:compact`).

Legacy `stablepulse:*` keys are migrated automatically on first load.

## Adding a stablecoin

The frontend is fully registry-driven. Adding a coin is **one config entry**:

```js
// src/utils/coin-config.js
USDE: {
  symbol: 'USDE',
  coingeckoId: 'ethena-usde',
  llamaStablecoinId: 'ethena-usde',   // DefiLlama stablecoin id
  color: '#8B5CF6',
  thresholds: { pegCriticalBps: 50, pegWarnBps: 10, chainSpikeUsd: 500e6, megaSupplyUsd: 1e9 },
},
// then add 'USDE' to ACTIVE_STABLECOINS
```

The nav tabs, home stats/charts, chain-flow bars, whale watch, and alerts all follow the list automatically. `coingeckoId` and `llamaStablecoinId` are consumed by the data layer to fetch prices and per-chain supply.

## AI configuration

AI runs on the **backend** (`backend/jobs/ai.js`); keys never reach the browser. Point it at any **OpenAI-compatible** endpoint via env vars in `backend/.env`:

| Env var | Example |
|---|---|
| `OPENAI_BASE_URL` | `https://api.openai.com/v1` or `https://openrouter.ai/api/v1` |
| `OPENAI_API_KEY` | your key |
| `OPENAI_MODEL` | `gpt-4o-mini` or `deepseek/deepseek-chat` |
| `OPENAI_FALLBACK_MODEL` | optional second model |
| `AI_CADENCE_MIN` | minimum minutes between narrative runs (default 120) |

- The narrative is generated by cron **in the background** so users never wait on the model.
- `/api/ai` returns the latest narrative plus `nextUpdateAt`/`cadenceMin`; the dashboard shows a last-updated/next-update ticker.
- The UI degrades gracefully if AI is down or absent, so the app keeps working either way.

## Deploying

### VPS (recommended, nginx)

1. `npm run build` and serve `dist/` from nginx.
2. Run the backend service (`backend/deploy/stablesense-backend.service`) on the same host, proxied under `/api` (`backend/deploy/nginx.conf`).
3. Add crontab entries for the fetch and AI jobs (`backend/deploy/crontab.txt`).
4. Same-origin serving means no CORS setup.

### Static anywhere (core dashboard only)

The frontend is static files with an optional AI base URL: deploy `dist/` anywhere and set `aiApiBase` if you run a backend. Without a backend, the dashboard still works fully (minus AI narratives and history accumulation).
